1. 학습 DB 열기

Guide: 사용 방법 / Lessons: 노트·어휘 / Questions: 문제·정답·해설

시트는 비공개로 둡니다. published가 TRUE인 학습 행만 공개됩니다.

2. GAS 코드 설치와 배포

  1. 위 시트에서 확장 프로그램 → Apps Script를 엽니다.
  2. Code.gs 내려받기 후 내용을 기존 빈 코드 대신 붙여 넣고 저장합니다.
  3. 상단 함수에서 setup을 선택해 실행하고, 본인 계정의 스프레드시트 접근을 승인합니다.
  4. 배포 → 새 배포 → 웹 앱을 선택합니다. 실행 사용자는 나, 액세스 사용자는 모든 사용자로 설정합니다.
  5. 배포 후 /exec로 끝나는 웹 앱 URL을 채리에게 보내 주세요. 로그인하지 않은 브라우저에서 열어 JSON이 보이는지 확인하면 됩니다.

이 코드는 공개 자료를 읽기만 합니다. 방문자는 이 API로 시트를 수정할 수 없습니다.

3. GitHub 저장소 준비

  1. GitHub 새 저장소 만들기에서 소유자를 Azolazol로 선택합니다.
  2. 저장소 이름은 mokun-study, 공개 범위는 Public, Add a README file을 켜고 생성합니다.
  3. 생성된 저장소 링크와 위 GAS 웹앱 URL을 채리에게 보내 주세요. 이 사이트의 코드와 데이터를 옮기고 연결할 수 있습니다.
  4. 직접 올릴 때는 배포 패키지의 docs, gas, tools, README.md를 저장소 루트에 올립니다.
  5. Settings → Pages → Deploy from a branch → main → /docs → Save를 선택합니다.

GitHub Pages 주소는 Pages 설정에 표시되는 실제 배포 URL을 확인하세요.

4. 연결 설정 파일

웹앱 URL을 넣으면 docs/config.js에 들어갈 코드를 만들어 줍니다. 이 화면은 GitHub 파일을 자동 수정하지 않습니다.

GAS 웹앱 주소를 입력하세요.

이후 수업 진도 추가

“국어 새 단원 자료를 추가해 줘”처럼 사진이나 범위를 보내 주세요. 채리가 같은 DB의 Lessons와 Questions에 새 행을 추가하는 방식으로 확장할 수 있습니다.

  • 기존 id는 유지합니다. 새 자료는 새로운 id를 사용합니다.
  • subject는 과목, term은 학습 범위, unit은 단원입니다. 새 값은 화면 목록에 자동으로 나타납니다.
  • 공개할 행만 published를 TRUE로 설정합니다.
  • 새 그림 파일은 GitHub의 docs/assets에도 추가해야 합니다.
  • GAS 연결 후 저장하고 사이트에서 자료 새로고침을 누르면 최신 공개 행을 읽습니다.
  • 연결 장애에 대비한 data.json은 tools/refresh-snapshot.mjs로 갱신하고 GitHub에 반영합니다.
